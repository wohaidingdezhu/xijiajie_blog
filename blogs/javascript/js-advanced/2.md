## new 做了什么

对普通构造函数执行 `new Person(name)` 时，可以把过程理解为：

1. 创建一个新对象。
2. 将新对象的原型连接到 `Person.prototype`；如果它不是对象，则使用 `Object.prototype`。
3. 以新对象作为 `this`，调用构造函数并传入参数。
4. 如果构造函数返回对象或函数，使用这个返回值；否则返回新对象。`null` 也属于后一种情况。

这描述的是普通构造函数的基本行为，详见 [MDN：new](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Operators/new)。

## 模拟普通构造函数

下面的实现用于理解对象、原型和返回值之间的关系，不修改内置方法。

```js
function newFactory(ctor, ...args) {
  if (typeof ctor !== 'function') {
    throw new TypeError('ctor 必须是函数');
  }

  const prototype = ctor.prototype;
  const isPrototypeObject = prototype !== null &&
    (typeof prototype === 'object' || typeof prototype === 'function');
  const instance = Object.create(isPrototypeObject ? prototype : Object.prototype);
  const result = Reflect.apply(ctor, instance, args);
  const isObject = result !== null && typeof result === 'object';

  return isObject || typeof result === 'function' ? result : instance;
}
```

这里直接使用 `Object.create(ctor.prototype)` 建立原型连接。先创建对象，再把它的原型设为 `Object.create(ctor.prototype)`，会多出一层原型。

`Reflect.apply` 的第三个参数是整个参数数组；不能把 `...args` 展开成多个参数传给它。

```js
function Person(name, age) {
  this.name = name;
  this.age = age;
}

Person.prototype.describe = function () {
  return `${this.name}，${this.age} 岁`;
};

const person = newFactory(Person, '小明', 18);
console.log(person.describe()); // 小明，18 岁
console.log(Object.getPrototypeOf(person) === Person.prototype); // true
console.log(person instanceof Person); // true

function ReturnNull() {
  this.ready = true;
  return null;
}
console.log(newFactory(ReturnNull).ready); // true

function ReturnObject() {
  return { ready: true };
}
console.log(newFactory(ReturnObject)); // { ready: true }
```

## 使用边界

这不是完整的 `new` 替代品：`class` 不能通过普通函数调用执行；箭头函数不能被 `new` 调用，而这里只检查了是否为函数；绑定函数、内置构造函数以及 `new.target` 也有额外规则。

业务代码应直接使用 `new`。如果构造函数和参数是动态传入的，可以使用 [Reflect.construct](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Reference/Global_Objects/Reflect/construct)：

```js
class User {
  constructor(name) {
    this.name = name;
  }
}

const user = Reflect.construct(User, ['小明']);
console.log(user.name); // 小明
```
