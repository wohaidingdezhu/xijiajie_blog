Canvas 可以用 JavaScript 在页面里绘制图形，适合画板、图表、图片处理等场景。这篇先练习 2D 绘图，再做一个支持鼠标和触摸的简单画板。

下面的代码片段分别演示一个知识点；最后提供一份可以直接保存为 HTML 文件运行的完整例子。

## 创建画布

先放一个画布，再获取 2D 上下文。脚本放在画布之后，避免获取元素时 DOM 还没有创建。

```html
<canvas id="canvas" width="600" height="320">
  这里展示 Canvas 绘图示例。
</canvas>
```

```js
const canvas = document.getElementById('canvas');
const ctx = canvas.getContext('2d');

if (!ctx) {
  throw new Error('无法获取 Canvas 2D 上下文');
}

ctx.fillStyle = '#26765e';
ctx.fillRect(30, 30, 120, 60);
```

画布坐标从左上角开始，向右是 x 轴正方向，向下是 y 轴正方向。上面的例子会在 `(30, 30)` 位置绘制一个宽 120、高 60 的绿色矩形。

`width`、`height` 属性决定画布的位图尺寸，CSS 决定页面里的显示尺寸。只修改 CSS 会缩放原有位图，比例不一致时还会拉伸图形；不指定属性时，位图默认为 300 × 150。参见 [MDN：Canvas 基本用法](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Basic_usage)。

## 矩形、线条和圆

矩形可以直接绘制，其他形状通常需要先创建路径。

```js
// 填充矩形、描边矩形和清除矩形区域
ctx.fillStyle = '#26765e';
ctx.fillRect(30, 30, 120, 60);
ctx.strokeStyle = '#293b36';
ctx.lineWidth = 2;
ctx.strokeRect(180, 30, 120, 60);
ctx.clearRect(50, 45, 30, 30);

// 画一条线
ctx.beginPath();
ctx.moveTo(30, 130);
ctx.lineTo(300, 130);
ctx.stroke();

// 画圆：圆心、半径、起始弧度、结束弧度
ctx.beginPath();
ctx.arc(90, 230, 35, 0, Math.PI * 2);
ctx.fill();
```

`beginPath()` 开始一条新路径，`moveTo()` 移动画笔，`lineTo()` 添加线段。路径本身不会显示，需要调用 `stroke()` 描边或 `fill()` 填充；`closePath()` 则把路径终点连接到起点。

画不同图形前记得调用 `beginPath()`，否则旧路径可能一起被再次绘制。`clearRect()` 清除的是位图像素，不会清空当前路径。路径和弧度的用法见 [MDN：绘制形状](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Drawing_shapes)。

## 文字与图片

文字的位置还受到基线影响，设置 `textBaseline = 'top'` 可以更直观地按左上角定位。

```js
ctx.font = '20px sans-serif';
ctx.textBaseline = 'top';
ctx.fillStyle = '#293b36';
ctx.fillText('Hello Canvas', 30, 30);
```

绘制图片时要等待加载完成，路径替换成项目中的真实图片地址。博客的头像就可以作为练习素材。

```js
const image = new Image();
image.onload = () => {
  ctx.drawImage(image, 30, 80, 100, 100);
};
image.onerror = () => {
  console.error('图片加载失败');
};
image.src = '/avatar.jpg';
```

`drawImage(image, x, y, width, height)` 可以把图片缩放到指定区域，也有裁剪源图片的九参数形式。使用外站图片并需要导出时，应在设置 `src` 前设置 `image.crossOrigin = 'anonymous'`，同时图片服务器必须允许跨域，否则导出可能失败。参见 [MDN：使用图片](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Using_images)。

## 变换与状态保存

`translate()` 移动坐标原点，`rotate()` 使用弧度旋转。变换会影响后续绘图，可以用 `save()` 和 `restore()` 隔离一段绘制操作。

```js
ctx.save();
ctx.translate(200, 150);
ctx.rotate(Math.PI / 4);
ctx.fillStyle = '#26765e';
ctx.fillRect(-30, -30, 60, 60);
ctx.restore();

// 这里已经恢复之前的坐标变换和绘图样式
ctx.strokeRect(30, 30, 80, 40);
```

它们保存和恢复的是坐标变换、颜色、线宽等绘图状态，不是画布上的像素，也不包含当前路径。如果要实现撤销，需要额外保存绘图操作或图像快照。更多说明见 [MDN：Canvas 坐标变换](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Transformations)。

## 高清屏适配

在高清屏上，可以增加位图像素数量，同时继续按 CSS 像素绘图。

```js
const width = 600;
const height = 320;
const dpr = window.devicePixelRatio || 1;

canvas.style.width = `${width}px`;
canvas.style.height = `${height}px`;
canvas.width = Math.round(width * dpr);
canvas.height = Math.round(height * dpr);
ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
```

例如 DPR 为 2 时，显示尺寸仍是 600 × 320，但位图约为 1200 × 640，绘图坐标仍然写 `(30, 30)`。参见 [MDN：高清屏适配](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Optimizing_canvas)。

`setTransform()` 会替换当前变换，适合设置基础缩放；连续调用 `scale()` 则会累积缩放。修改 `canvas.width` 或 `canvas.height` 会清空画布并重置绘图状态，所以调整尺寸后需要重新设置变换、样式并重绘内容。参见 [MDN：setTransform](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/setTransform) 和 [MDN：画布宽度](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/width)。

## 完整例子：一个简单画板

把下面代码保存为 `canvas.html`，用浏览器打开即可。按住鼠标左键或在触摸屏上拖动可以绘图，点击“清空”重新开始，点击“导出 PNG”保存图片。

这个例子使用固定的逻辑坐标和响应式显示尺寸。指针坐标需要从页面坐标换算到画布坐标，不能直接使用 `clientX`、`clientY`；高清屏的缩放已经由上下文处理，不需要再次乘 DPR。

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Canvas 画板</title>
  <style>
    body { margin: 24px; color: #293b36; font-family: sans-serif; }
    canvas {
      display: block;
      width: 600px;
      max-width: 100%;
      height: auto;
      outline: 1px solid #e7ece9;
      touch-action: none;
    }
    button { margin: 16px 8px 0 0; padding: 8px 16px; }
  </style>
</head>
<body>
  <h1>Canvas 画板</h1>
  <p>按住鼠标左键或用手指拖动，绘制一条线。</p>
  <canvas id="board" aria-label="可用鼠标或触摸绘制的画板">
    画板支持绘制线条，并通过下方按钮清空或导出图片。
  </canvas>
  <button id="clear" type="button">清空</button>
  <button id="export" type="button">导出 PNG</button>

  <script>
    const canvas = document.getElementById('board');
    const ctx = canvas.getContext('2d');
    if (!ctx) throw new Error('无法获取 Canvas 2D 上下文');

    const width = 600;
    const height = 320;
    const dpr = window.devicePixelRatio || 1;
    canvas.width = Math.round(width * dpr);
    canvas.height = Math.round(height * dpr);
    ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    ctx.lineWidth = 3;
    ctx.lineCap = 'round';
    ctx.strokeStyle = '#26765e';
    ctx.fillStyle = '#26765e';

    let pointerId = null;
    let lastPoint = null;
    let downloadUrl = null;

    function clearBoard() {
      pointerId = null;
      lastPoint = null;
      ctx.save();
      ctx.fillStyle = '#fff';
      ctx.fillRect(0, 0, width, height);
      ctx.restore();
      ctx.beginPath();
    }

    function getPoint(event) {
      const rect = canvas.getBoundingClientRect();
      return {
        x: (event.clientX - rect.left) * width / rect.width,
        y: (event.clientY - rect.top) * height / rect.height,
      };
    }

    canvas.addEventListener('pointerdown', (event) => {
      if (!event.isPrimary || event.button !== 0 || pointerId !== null) return;
      pointerId = event.pointerId;
      lastPoint = getPoint(event);
      canvas.setPointerCapture(pointerId);
      ctx.beginPath();
      ctx.arc(lastPoint.x, lastPoint.y, ctx.lineWidth / 2, 0, Math.PI * 2);
      ctx.fill();
    });

    canvas.addEventListener('pointermove', (event) => {
      if (event.pointerId !== pointerId) return;
      const point = getPoint(event);
      ctx.beginPath();
      ctx.moveTo(lastPoint.x, lastPoint.y);
      ctx.lineTo(point.x, point.y);
      ctx.stroke();
      lastPoint = point;
    });

    function stopDrawing(event) {
      if (event.pointerId !== pointerId) return;
      pointerId = null;
      lastPoint = null;
    }

    for (const type of ['pointerup', 'pointercancel', 'lostpointercapture']) {
      canvas.addEventListener(type, stopDrawing);
    }
    document.getElementById('clear').addEventListener('click', clearBoard);
    document.getElementById('export').addEventListener('click', () => {
      canvas.toBlob((blob) => {
        if (!blob) return;
        if (downloadUrl) URL.revokeObjectURL(downloadUrl);
        downloadUrl = URL.createObjectURL(blob);
        const link = document.createElement('a');
        link.href = downloadUrl;
        link.download = 'canvas.png';
        document.body.appendChild(link);
        link.click();
        link.remove();
      }, 'image/png');
    });
    window.addEventListener('beforeunload', () => {
      if (downloadUrl) URL.revokeObjectURL(downloadUrl);
    });
    clearBoard();
  </script>
</body>
</html>
```

这里用 Pointer Events 统一鼠标、触摸和触控笔输入。`setPointerCapture()` 可以继续接收移出画布后的指针事件；`pointercancel` 和 `lostpointercapture` 则用于结束异常中断的绘制。`touch-action: none` 只禁用画板区域的触摸滚动。参见 [MDN：Pointer Events](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events)。

示例先绘制了白色背景，因此导出的 PNG 也有白底；单纯设置 CSS 背景不会改变导出的像素。`toBlob()` 返回图片数据，生成的对象 URL 在下一次导出或关闭页面时释放。参见 [MDN：toBlob](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/toBlob)。

## 动画与页面离开时的清理

动画通常是“清除上一帧，再绘制下一帧”。使用 `requestAnimationFrame()`，根据时间计算位置，避免动画速度随屏幕刷新率变化。

下面是一段独立练习，放在已经初始化好 `canvas`、`ctx` 的页面里运行。它会持续重绘整张画布，不要与上面的画板逻辑同时运行。

```js
let frameId;
let startTime;

function drawFrame(time) {
  if (startTime === undefined) startTime = time;
  const x = 20 + ((time - startTime) * 0.1) % 560;

  ctx.clearRect(0, 0, 600, 320);
  ctx.beginPath();
  ctx.fillStyle = '#26765e';
  ctx.arc(x, 160, 15, 0, Math.PI * 2);
  ctx.fill();
  frameId = requestAnimationFrame(drawFrame);
}

frameId = requestAnimationFrame(drawFrame);

function stopAnimation() {
  cancelAnimationFrame(frameId);
}
```

组件卸载时要调用 `stopAnimation()`，并移除自己注册的全局事件监听。Vue 2 可以在 `beforeDestroy` 中清理，Vue 3 可以在 `onUnmounted` 中清理。浏览器通常会在后台标签页暂停动画回调，页面恢复后可能出现时间跨度较大的情况；游戏或物理模拟还应限制每帧的时间差。参见 [MDN：Canvas 基础动画](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API/Tutorial/Basic_animations)。

## 常见问题

| 现象 | 排查方向 |
| --- | --- |
| 图形模糊或被拉伸 | 检查位图尺寸、CSS 显示尺寸和 DPR 是否匹配 |
| 画新线时旧线也出现 | 新图形前调用 `beginPath()` |
| 点击位置和绘制位置不一致 | 用 `getBoundingClientRect()` 换算坐标，注意 CSS 缩放 |
| 调整尺寸后画面消失 | 重设宽高会清空画布，需要恢复状态并重绘 |
| 导出图片没有 CSS 背景 | 将背景颜色实际绘制到位图里 |
| 外站图片能显示但无法导出 | 检查图片的 CORS 响应和 `crossOrigin` 设置 |

Canvas 绘制后的内容没有单独的 DOM 节点，交互、文字说明和键盘操作需要自己补充。静态图标、需要逐个元素交互的图形，也可以考虑 SVG；普通文本和表单继续使用 HTML 会更方便。
